# handrolled
A handwritten chatbot architected from scratch to understand the foundations, the architectural decisions and every single decision.

## Rung 1
Rung 1 is the first version of this app that is basically a simple 10-15 line code which replies to specific keywords with canned responses by using the keyword to find key of replies dictionary. This is a simple find and reply program which will eventually evolve into a full-fledged RAG application.

## How to run
- Clone the repo: `git clone https://github.com/razi03/handrolled`
- Make sure python is installed and up to date.
- Open terminal and navigate to the project directory.
- Run using command `python3 bot.py`
